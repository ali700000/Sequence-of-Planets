# Project Title

Sequence of Planets

## Project Option

Simple Browser Game

## Project Description

Sequence of Planets is a simple browser game. In the game, players complete a mission by clicking planets in the correct order in the solar system. The game gives instructions to the player to help them progress through the game. Selecting the correct planets allows the player to progress through the game, while selecting the incorrect option requires the player to restart the game. I used HTML to structure the game. I used CSS to add visuals to the game. I used JavaScript to add feedback, logic, and player progress.

## Theme Interpretation

This project responds to the theme of space through planetary exploration. The player will interact with planets in space and learn about what they planets are and the correct sequence to click them.

## Intended User or Player

The intended players for this game are college students who enjoy simple browser games involving space and planets. This game is designed for beginners. Players should be able to easily understand the premise of the game and know how to complete the game.

## User or Player Goal

The main goal for the player is to click all of the planets in the correct sequence and complete the space mission.

## Main Features

Title screen and start button
Sequence of planets system
Player progress display
Correct and incorrect click detection
Restart button
Space-themed game interface

## JavaScript Features

Start button: JavaScript will start the game when the player clicks the button.
Sequence of planets system: JavaScript will give instructions on what planet the player is supposed to click.
Player progress display: JavaScript will let the player know how many planets the player has correctly selected.
Correct and incorrect click detection: JavaScript will determine whether the planet the player clicks is correct or incorrect.
Restart button: JavaScript will restart the game if the player selected the incorrect planet and clicks the button.

## Responsive Design

The game controls will be vertical on mobile devices. The instructions, restart button, and progress display will be vertical.
The text will be smaller for mobile devices. The instructions and title of the game will have a smaller font size to make sure the screen is organized.

## User Testing

When players entered the game, they understood that the game involved clicking planets in the correct order. They understood the space theme of the game. The “start mission” button was in the middle of the screen and players could see it. The correct and incorrect messages helped players know if they clicked the right planet or not. Some players mentioned that instructions should be included in the beginning of the game so players know what the objective is. When the players were testing the game, they noticed a lot of things that were missing and things that weren’t working in the game. They noticed that they could click the planets before starting the game. They noticed that the game didn’t have a lot of visuals. Much of the gameplay worked, but there were some things that could have been added. Overall, the gameplay worked decently but there were a lot of things that were missing.
